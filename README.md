# SmileCare | Dental Clinic Website

A fully responsive landing page for a dental clinic in Cairo, Egypt, built with **HTML**, **Tailwind CSS** and **FontAwesome**.

**Live demo:** https://ahmed03ayman.github.io/SmileCare-dental-clinic/

## Features

- Sticky, responsive header that adapts to mobile, tablet and desktop
- Hero section with call-to-action buttons and hover/focus states
- Services cards with hover effects (General Dentistry, Orthodontics, Implants & Surgery)
- Stats banner with decorative gradient background
- Medical team cards with social links revealed on hover
- Contact form, clinic information and working hours
- Footer with social icons

## Built With

- HTML5
- [Tailwind CSS](https://tailwindcss.com/) (v4, CLI)
- [FontAwesome](https://fontawesome.com/) icons

## Run Locally

```bash
# 1. Clone the repository
git clone https://github.com/Ahmed03Ayman/SmileCare-dental-clinic.git
cd SmileCare-dental-clinic

# 2. Install dependencies
npm install

# 3. Build the CSS (keeps watching for changes)
npx tailwindcss -i ./css/style.css -o ./css/output.css --watch
```

Then open `index.html` in your browser.
